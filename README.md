## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Material Library** | Save cut pressure and speed presets per material type |
| **Design Manager** | Organize SVG and cut designs by project and material |
| **Job Log** | Track completed cuts with material usage and blade wear notes |
| **Blade Profiles** | Save blade offset and force settings per blade type |
